# Where every asset comes from

Sonny's Arcade contains no image, sound or font files from other games, and no copyrighted characters.

| Asset | Where it lives | Origin |
|---|---|---|
| Sonny, Dada, Mama sprites (pajamas, hero suit, rocket suit) | `games/superheroville/src/art.js` | Original pixel art drawn in code, based on the family's own book *Sonny and the Two Sides of the Street*. The book's Superman "S" is replaced by Sonny's own yellow emblem. |
| Monsters: skeleton, pumpkin, bat, mummy, werewolf, ghost, zombie hand, Count Snoozula | `art.js` | Original pixel art. Classic public-domain Halloween monsters, nothing from the book's licensed characters. |
| Power-ups: candy, Hero Cape, Rocket Suit, Hero Star, Dino Egg | `art.js` | Original pixel art |
| Tiles, houses, moon, scenery, backgrounds | `art.js` | Original, generated in code |
| Pixel font | `games/superheroville/src/font.js` | Original 5x7 font drawn in code |
| Music (7 songs) and sound effects | `games/superheroville/src/sound.js` | Original compositions, played by a Web Audio chiptune synth written for this project |
| Game engine | `games/superheroville/lib/phaser.min.js` | Phaser 3.90.0, MIT licence (`lib/PHASER-LICENSE.md`) |
| Launcher | `index.html` | Original. Its pictures reuse `art.js`. |

## What the game borrows from classics (ideas only)

Superheroville follows the *style* of the classic Mario games: running and jumping, stomping
enemies, blocks with power-ups, pipes, a flagpole at the end of each level, World 1-1 to 1-4.
Game mechanics like these aren't owned by anyone. The game uses no Nintendo names, characters,
graphics, music or sounds, and the Rocket Suit is its own design (red and gold with a jetpack).
